
📦 Smart Inventory
نظام عربي متكامل لإدارة المخزون والمخازن
إدارة الأصناف والمخازن، أذونات الإضافة والصرف والتحويل، كشوف حساب الموردين والعملاء، تحليل تكلفة المباني، توقعات نفاد المخزون، وتقارير تنفيذية يومية — في تطبيق ويب واحد يعمل على الموبايل كـ PWA.
المميزات
المخزون والحركات
الأصناف والمخازن: أرصدة لكل صنف في كل مخزن، صور للأصناف، بحث متقدم وفلاتر على الأعمدة، وتثبيت الأعمدة في الجداول.
أذونات المخازن: إضافة، صرف، تحويل بين المخازن، مرتجعات، وتسويات مخزنية — مع رفع صور الأذونات ومعاينتها.
تقرير الجرد الشامل: أرصدة الأصناف حسب كل مخزن.
المسودات: حفظ الأذونات والملاحظات قبل الاعتماد.
الصرف السالب / التسويات: معالجة الحالات الاستثنائية مع سجل تدقيق كامل.
الحسابات
الموردون والعملاء/جهات الصرف: دليل كامل وكشف حساب لكل طرف، مع تفاصيل مالية للحركات.
تحويل أرصدة العملاء مع تسوية (netting) تلقائية.
التحليلات والتقارير
مقارنة المباني والتكاليف: ربط الصرف بمبنى (٥ مباني مملوكة + مقاول/جهة خارجية)، ميزانية لكل مبنى، ومقارنة التكلفة.
توقع نفاد المخزون: معدل الاستهلاك وعدد الأيام المتبقية، مع إعدادات مدة التوريد ومخزون الأمان.
تحليلات الاستهلاك وتقارير الحركة والأرصدة والفروقات، مع تصدير Excel وPDF.
تقرير تنفيذي يومي مجدول (الساعة 5 مساءً بتوقيت القاهرة افتراضيًا، قابل للتعديل): ملخص الصرف، الأصناف الحرجة، تنبيهات المباني، والأصناف بدون مبنى — يُرسل بالإيميل وإشعارات داخلية للمديرين وواتساب.

### جدولة التقرير اليومي (cron-job.org)

لأن خطة Vercel Hobby لا تشغّل Cron أكثر من مرة يوميًا، يمكن استخدام cron-job.org لإرسال طلب `POST` كل 5 دقائق إلى:

```text
https://YOUR-DOMAIN/api/scheduled/daily-report-heartbeat
```

أضف رأس الطلب التالي، مع استخدام نفس قيمة `CRON_SECRET` في Vercel وRender:

```text
Authorization: Bearer YOUR_CRON_SECRET
```

إذا لم يحِن وقت التقرير أو كان قد نجح بالفعل في يوم القاهرة الحالي، تكون الاستجابة مثل:

```json
{"ok":true,"status":"skipped","reason":"not-due"}
```
التواصل والتنبيهات
محادثات فريق العمل داخل النظام مع إيصالات القراءة.
مركز إشعارات وتنبيهات المخزون المنخفض.
إشعارات واتساب عبر WhatsApp Cloud API (اختياري).
بحث صوتي واستعلام عن الرصيد بالصوت (عربي).
تسجيل الدخول عبر Google OAuth مع إبطال الجلسات وسجل دخول وتدقيق كامل.
الأمان والحوكمة
٧ أدوار (admin, manager, operator, reviewer, reports, viewer, user) مع صلاحيات تفصيلية لكل شاشة ولكل مخزن.
مركز النسخ الاحتياطي: نسخ كاملة في تخزين دائم، واختبار استعادة معزول على قاعدة منفصلة مع مقارنة أعداد الصفوف وتنبيه بالإيميل عند الفشل. قاعدة الإنتاج لا تُمس أثناء الاختبار.
حزمة ترحيل لنقل البيانات والصور مع التحقق من SHA-256.
تجربة الاستخدام
واجهة عربية RTL متجاوبة، وضع فاتح/داكن، وجولة تعريفية للمستخدم الجديد.
PWA: تثبيت على الموبايل، تحديثات تلقائية، وعمل دون إنترنت مع طابور مزامنة للعمليات.
اختصارات لوحة المفاتيح لسطح المكتب (مثل Alt + I للإضافة وAlt + O للصرف).
